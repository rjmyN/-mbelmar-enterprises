In your domain registrar, add these DNS records:

```

TTL: Automatic

Type: A

Name: www

```

### Step 3: Connect Domain to GitHub

1. Go to: https://github.com/rjmyN/-mbelmar-enterprises/settings/pages
2. Under "Custom domain", enter your domain: `belmarenterprises.com`
3. Click **Save**
4. Wait 24-48 hours for DNS propagation
5. Check **"Enforce HTTPS"** (will be available after DNS is active)

## 🆘 Troubleshooting

### Contact Form Not Working?
- Check admin@belmarenterprises.com for confirmation email
- Click confirmation link from Formspree
- Check spam/junk folder
- Test again after confirming

### Website Not Loading?
- GitHub Pages takes 1-2 minutes to update
- Clear browser cache (Ctrl+Shift+R)
- Try incognito/private mode
- Check GitHub repository settings

### Changes Not Showing?
- Wait 1-2 minutes for GitHub Pages to rebuild
- Clear browser cache
- Check if files were pushed to GitHub

### Custom Domain Not Working?
- DNS propagation takes 24-48 hours
- Verify DNS records are correct
- Check GitHub Pages settings
- Use DNS checker: https://dnschecker.org
