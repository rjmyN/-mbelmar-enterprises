## 📂 STEP 3: Access Your Hosting (2 minutes)

1. Go to: **https://account.godaddy.com/products**

2. Scroll down to find **"Web Hosting"** section
   - (It might take 5-10 minutes to appear after purchase)

3. Click **"Manage"** button next to your hosting

4. This opens **cPanel** (your control panel)

---

## 📤 STEP 4: Upload Your Website (5 minutes)

### In cPanel:

1. Find section called **"Files"**

2. Click **"File Manager"**

3. A new tab opens with your files

4. Click on **"public_html"** folder (double-click to open it)

5. **Delete everything inside** (if there are any files):
   - Click top checkbox to select all
   - Click **"Delete"** button
   - Confirm deletion

6. Make sure you're still in **public_html** folder

7. Click **"Upload"** button at the top

8. Click **"Select File"** button

9. Go to your **Desktop**

10. Select **mbelmar-website.zip**

11. Click **"Open"** and wait for upload (shows progress bar)

12. After upload completes, click **"Go Back to..."** link

13. You'll see **mbelmar-website.zip** in public_html

14. **Right-click** the ZIP file

15. Select **"Extract"**

16. Click **"Extract Files"** button

17. Wait for extraction (5-10 seconds)

18. You'll now see all your website files:
    - index.html
    - privacy.html
    - styles.css
    - logo.jpg
    - etc.

19. **Delete mbelmar-website.zip** (right-click → Delete)

✅ **Done uploading!**

---

1. Wait 2-5 minutes for everything to process

2. Open your browser

3. Go to: **https://mbelmarenterprises.com**

## 🆘 Troubleshooting

**Script won't run?**
- Right-click → "Run with PowerShell"
- If blocked, open PowerShell as Administrator:
  ```powershell
  Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Bypass
  ```
  Then try again

**Don't see Web Hosting after purchase?**
- Wait 10-15 minutes
- Refresh the page
- Check your email for confirmation

**Can't find File Manager in cPanel?**
- Look in the "Files" section
- It's usually the first or second icon
- Has a folder icon

**Upload failing?**
- Make sure file is under 500MB (yours is tiny, so OK)
- Try uploading again
- Close and reopen File Manager

**Website not loading?**
- Wait 5-10 minutes
- Clear browser cache (Ctrl+Shift+R)
- Try incognito mode
- Check if domain is pointing to hosting (GoDaddy does this automatically)
